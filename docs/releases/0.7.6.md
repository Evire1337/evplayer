v0.7.6

desktop:
• Песни с YouTube Music играют в полной версии, без запикивания: если у песни есть версия с пометкой «E» (explicit), берётся она. Это касается поиска, импорта из других сервисов и песен, которые играют с YouTube Music вместо SoundCloud. Уже сохранённые песни сами находят свою версию без цензуры
• Лайки и плейлисты не пропадают, если закрыть, обновить или аварийно завершить EvPlayer сразу после изменения: рядом с данными хранится вторая копия, и при запуске берётся более свежая
• Если SoundCloud, YouTube Music и другие сервисы у вас не открываются без VPN, можно указать свой прокси: Настройки → Сервисы → «Свой прокси» (адрес вида 127.0.0.1:7890, подойдёт HTTP-порт Clash, v2rayN или Hiddify). Через него идут поиск, песни и скачивание. Заработает после перезапуска
• Текст песни с временем следует за певцом только если версия песни в базе совпадает с вашей по длине (до 3 секунд). Иначе слова показываются без времени, а не убегают вперёд
• Linux: громкость 0 теперь действительно выключает звук
• Windows 11: окно управления мультимедиа получило собственное имя приложения EvPlayer
